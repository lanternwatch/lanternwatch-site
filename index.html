Why Lantern Watch is different

Most parental control tools ask you to trade your family's privacy for protection. We don't.

Cloud Subscription Tools

  • ❌ Costs $100–$200+ every single year in recurring subscription fees.
  • ❌ Sends every search query and website visit to corporate cloud servers.
  • ❌ Easily bypassed by tech-savvy kids (deleting apps, VPNs, alternate browsers).
  • ❌ When you stop paying, all family protection disappears immediately.

Lantern Watch

  • ✓ Free forever: No monthly subscriptions, no paywalls, no upsells.
  • ✓ 100% Private: Everything runs locally on your router. Zero cloud logging.
  • ✓ Whole-home coverage: Filters every phone, tablet, laptop, and smart TV automatically.
  • ✓ Unbypassable: Operates at the DNS gateway before data ever hits devices.
What it does

Protection that lives in your home

Everything runs locally on a small router you own. Your family's activity never leaves the house.

Content filtering

Blocks adult content, malware, and trackers at the DNS level for every device on the network — no app to install on each phone.

Screen time & schedules

Set bedtimes, focus hours, and daily limits. Pause the internet for any device with one tap when it's time for dinner.

Per-device control

See every device on your network and manage each one individually — kids' tablets, the family TV, guest phones.

Gentle alerts

Optional notifications to a parent's phone when something needs attention — delivered privately via ntfy, Telegram, or email.

Grace-filled block page

When a blocked site is hit, kids see a warm reminder with Psalm 119:105 and a link to helpful resources — encouragement, not shame.

Open & auditable

Every line of code is public on GitHub under the MIT license. Anyone can inspect exactly what it does — nothing hidden.

Installing Lantern Watch is as easy as 1-2-3

Install directly through your GL.iNet router panel with zero command-line tools needed.

Full installation guide →
Step 1

Add the source

In the GL.iNet panel: Applications → Plug-ins → Manage Sources.

Add:
Name lanternwatch
URL https://lanternwatch.org/repo
then Apply.

Step 2

Install it

Click Refresh, search lanternwatch, and click Install. Give it about two minutes.

Step 3

Set your password

Open http://192.168.8.1:8081 and choose a password. That's it — protection is already on.
